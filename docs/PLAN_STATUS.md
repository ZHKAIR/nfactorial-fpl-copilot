## 2. Где план изменился и почему

| было в плане | стало | почему |
|---|---|---|
| Фреймворки запрещены (`project_context.md` §15) | **LangGraph — только для агентного слоя**; ML, оптимизатор, RAG, vision — обычные модули | задание требует LangGraph/CrewAI/Parlant с ветвлениями, циклом и HITL; графу состояний с чекпоинтером это нужно ровно в агенте, остальным — нет (`gaps.md` §2, `docs/ARCHITECTURE.md` §6) |
| Использовать существующий FPL MCP для низкоуровневых данных (`project_context.md` §4) | **собственный тонкий клиент** `data/fpl_client.py` (только чтение, дисковый кэш) | чужие серверы — обёртки над теми же REST-эндпоинтами без кэша; в час дедлайна API нестабилен, и кэш стал частью дизайна; свой MCP отдаёт решения, а не факты (`docs/mcp.md`) |
| Убрать multi-GW планирование из MVP (`gaps.md` §5) | **планировщик на 5 туров остался** | одна MILP-формулировка обслуживает XI, одиночный трансфер и план — цена добавления была низкой, а сравнение с Wildcard и накопление FT без горизонта не посчитать; план — интент агента, инструмент MCP и страница UI (`docs/optimizer.md`) |
| Odds как отдельный модуль (`project_context.md` §7) | **odds — внутренний вход модели xPts**; до 22.09 — stub до ключа, с 22.09 работает (The Odds API, `v0-odds` для GW6), дефолт — `team_rating` | математика (`remove_margin`, сетка Пуассона под 1X2 и тотал) реализована и покрыта тестами; `fetch_snapshot()` ждёт бесплатный ключ The Odds API; пользователю показывается только индекс FSI 1–5, инструменты о ставках не говорят |
| xPts v0 = `ep_next` FPL + поправка новостей (`gaps.md` §5) | **компонентная модель v0** по правилам FPL со сжатием к приорам | `ep_next` не раскладывается на компоненты, а агент должен объяснять «почему»; v0 бьёт бейзлайны на GW2–4 и даёт живой эксперимент против `ep_next` на GW5 (`docs/xpts.md`) |
| LightGBM / XGBoost / CatBoost (`project_context.md` §5) | **отложено до v1** | 4 тура данных 2026/27 — обучать нечего; нужен vaastav 2016–2026 |
| Next.js + FastAPI (`project_context.md` §15) | **Streamlit** | один пользователь на демо, нет бизнес-логики в UI; снижение риска по `gaps.md` §2 |
| OR-Tools (`project_context.md` §9) | **PuLP + HiGHS** (`highspy`) | формулировка open-fpl-solver уже на PuLP; CBC из PuLP не запускается на macOS arm64, HiGHS ставится колесом |
| Qdrant или pgvector | **pgvector** | фильтр `published_at <= as_of` — одно условие в SQL рядом с данными; один процесс БД |
| Мультимодальность: vision или audio (`gaps.md` §1) | **vision** (скриншот состава) | без него приложение не знает текущий состав — публичный API отдаёт picks только за завершённые туры |
